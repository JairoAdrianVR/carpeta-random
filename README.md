1er comando -> GIT INIT -> AVISA QUE ESTO ES UN REPOSITORIO GIT
2do comando -> GIT ADD -> Avisa a los ARCHIVOS para decirles que juegan en la version final
3er comando -> GIT STATUS -> Nos deja ver en que estado estan los archivos
4to comando -> GIT COMMIT -> Dejamos los archivos que agregamos, en la version final
5to comando -> git branch -M -> Cambia el nombre de la rama en la que estamos 
6to comando -> git remote add origin https://github.com/JairoAdrianVR/carpeta-random.git
7mo comando -> git push -u origin <nombre-rama> ->  ENVIA LOS ARCHIVOS A GITHUB
